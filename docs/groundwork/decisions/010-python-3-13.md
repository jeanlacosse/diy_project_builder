# 010. Python 3.13 instead of 3.12

_Status: accepted_ · _Date: 2026-11-05_

## Context
Decision 001 chose Python 3.12. The owner's machine has Python 3.13 (Homebrew's default is newer still), and nothing in the project needs 3.12 specifically. The slice 01 build used 3.13, with `uv` fetching its own interpreter.

## Decision
The project targets Python 3.13: `requires-python = ">=3.13"` and `.python-version` set to `3.13`. The rest of decision 001 (uv, pytest, ruff, mypy, Pydantic as the contract) is unchanged.

## Alternatives considered
| Option | Why not |
|---|---|
| Stay on 3.12 | No project need for it; the owner prefers 3.13, and it would mean a second interpreter |
| Track the newest Python (3.15) | Dependencies may lag; 3.13 is stable and enough |

## Consequences
Friends running the CLI (slice 15) need Python 3.13 or later, which `uv` can fetch. Docs and tests that said 3.12 are updated to 3.13.
